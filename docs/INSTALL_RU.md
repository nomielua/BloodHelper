# Установка BLOODHELPER 1.1.0+1.21.11

Инструкция относится к целевой сборке для Minecraft 1.21.11. Интеграция версии
1.1.0 продолжается; указание имени JAR не означает, что релиз опубликован или
прошёл игровые проверки. Их статус фиксируется отдельно в
[VERIFICATION_RU.md](VERIFICATION_RU.md).

## Что нужно

| Компонент | Версия |
| --- | --- |
| Minecraft Java Edition | **1.21.11** |
| Java для запуска игры | **21 или новее** |
| Fabric Loader | **0.18.6 или новее**; сборка разработана с 0.19.5 |
| Fabric API | Сборка **для 1.21.11**; в проекте используется 0.141.6+1.21.11 |
| BLOODHELPER | Собранный `BloodHelper-1.1.0+1.21.11.jar` |

Установить Fabric можно через настройки загрузчика своего лаунчера или
[официальный установщик Fabric](https://fabricmc.net/use/installer/).
[Fabric API](https://modrinth.com/mod/fabric-api/versions?g=1.21.11) помещается
в `mods` отдельным JAR. Выбирай именно Minecraft 1.21.11.

Для музыки дополнительно нужна Windows 10 версии 1809 или новее либо Windows 11,
штатный Windows PowerShell и проигрыватель с системной медиасессией. Для одних
HUD, счётчиков и интерфейса Windows не требуется.

## Установка в свой профиль

1. Выбери профиль **Minecraft 1.21.11 с Fabric** в лаунчере. Открой его папку
   через действие «Открыть папку» / «Open folder» у этого профиля.
2. Если игра из этого профиля запущена, выйди из неё перед заменой файлов модов.
3. Открой или создай папку `mods` внутри папки профиля.
4. Скопируй туда `BloodHelper-1.1.0+1.21.11.jar` и совместимый Fabric API.
   При обновлении убери предыдущий JAR BLOODHELPER из `mods`, чтобы не загружать
   две версии одного мода. Резервную копию можно хранить вне этой папки.
   Файл `-sources.jar` в `mods` не нужен.
5. Запусти выбранный профиль и войди в свой мир или на сервер.
6. Нажми **правый Shift**, чтобы открыть BLOODHELPER.

В обычном лаунчере папка игры часто находится в `%APPDATA%\.minecraft`, но у
Modrinth App, Prism и других менеджеров каждый профиль может иметь свою папку.
Используй папку именно запускаемого профиля.

BLOODHELPER устанавливается на стороне игрока; установка мода или изменение
настроек сервера не требуются. Cloth Config, Mod Menu и
отдельный Changes for Cooldown ему не нужны. Если ранее использовался Changes
for Cooldown, его можно убрать из этого профиля для устранения дублирующихся
индикаторов. Исходный JAR при желании сохрани вне `mods`.

## Первые настройки

В **Visuals** находятся восемь карточек в двух колонках: Cooldowns, PvP Timer,
Dynamic Island, Notifications, Item Counter, Armor HUD, Performance и
Session Stats. По умолчанию карточки свёрнуты: нажми на заголовок, чтобы
раскрыть настройки внутри карточки. Enable включает и выключает сам модуль.
Названия английские, описания по умолчанию русские.

**Кулдауны.** Открой **Visuals → Cooldowns**: настрой отображение
названий и полоски прогресса. Фон и расположение находятся в **More settings**.
Индикаторы появляются, когда
Minecraft сообщает активную перезарядку предмета.

**PvP.** По умолчанию группа равна `minecraft:trident`. Она означает PvP только
на сервере, использующем её для таймера боя. Мод не определяет бой по ударам.
Если сервер использует другую группу, укажи её в настройке PvP; значение
должно быть идентификатором вида `namespace:group`. Если такой группы нет,
строка таймера не появляется.

**Музыка.** Включи песню в приложении Windows и открой настройки Dynamic Island.
Выбранная системой медиасессия передаёт название, исполнителя, обложку и прогресс.
Если приложений несколько, выбранное Windows приложение может отличаться от
последнего окна, которое ты открыл.

**С текстом или без.** Внутри Dynamic Island найди **Lyrics** и выбери
Off, Island, World (3D) или Island + 3D. Для режима с
текстом нужны интернет и синхронизированный текст песни в LRCLIB. Запросы
текста содержат название трека, исполнителя и известную длительность; режим
Off отключает такие запросы.

**Управление плеером.** В игре открой чат клавишей `T`, затем нажми предыдущий
трек, паузу/продолжение или следующий трек на островке. Команды также есть
в настройках Dynamic Island при обнаруженном плеере. Отключи компактный вид,
если нужны текст и кнопки на самом островке.

**Предметы.** Раскрой **Item Counter**, отметь нужные предметы в готовом списке
или возьми предмет в основную руку и нажми **Add held item**. Можно выбрать до восьми типов.
По умолчанию считаются тотемы, эндер-жемчуг, золотые яблоки и стрелы.
Учитываются 36 основных слотов собственного инвентаря и вторая рука по одному
разу; открытый контейнер и предмет на курсоре не учитываются. Кастомные
предметы с одинаковым registry ID объединяются. Настрой подписи, скрытие
нулей и порог низкого остатка, если нужно.

**Броня.** В **Armor HUD** выбери проценты или оставшиеся единицы прочности,
названия и скрытие при отсутствии надетой брони. Начальный порог предупреждения
равен 20%. Этот порог используется и предупреждениями Notifications.

**Уведомления.** В **Notifications** доступны предупреждения о броне, запасе
выбранных предметов и окончании полезных эффектов. По умолчанию звук выключен,
показываются до трёх карточек по четыре секунды, порог эффектов — 10 секунд.
Уже низкое значение при входе не вызывает уведомление: нужен переход сверху
через порог. Кнопка Test показывает пример. Отдельного Effects HUD нет,
обычное отображение эффектов Minecraft остаётся прежним.

**Производительность.** В **Performance** включи нужные FPS, интервал кадров,
график и ping. Если клиенту неизвестен ping, выводится `—`; это не показатель
нулевой задержки. Модуль не измеряет TPS сервера.

**Сессия.** В **Session Stats** по умолчанию выбран **FFA**: два счётчика
убийств, всего и с монетной наградой, плюс необязательное время. Учитываются
только [два заданных формата серверных сообщений](MODULES_1_1_RU.md#ffa): награда
увеличивает оба счётчика, отказ в награде — только общий. **SMP / MEETUPS**
используют доступные vanilla-события для убийств, смертей, K/D и серии.
Для нестандартных сообщений предусмотрен явно заданный шаблон в конфигурации;
порядок настройки описан в [разделе о сессии](MODULES_1_1_RU.md#smp-и-meetups).
**Смена режима сбрасывает сессию.** По умолчанию она также сбрасывается при
отключении; ручной сброс доступен в карточке. Нераспознанные или пропущенные
события не восстанавливаются по догадке.

**Расположение.** Нажми **HUD Editor** в левой части меню. Перетащи блоки мышью.
Колесо над блоком меняет масштаб, `R` сбрасывает расположение, `Esc` сохраняет
и возвращает в меню. В редакторе есть демонстрационные данные для отсутствующих
таймеров и новых модулей; они не влияют на реальные уведомления и статистику.
Все пять новых HUD перемещаются и масштабируются отдельно. Общие фон и тень
находятся в Appearance, локальные переключатели — внутри каждой новой
карточки. Общий выключатель имеет приоритет.

**Клавиша меню.** В разделе **Appearance → Menu key** нажми текущую клавишу и затем новую.
`Esc` отменяет выбор, `Backspace` возвращает правый Shift.

**Размер и язык.** **Appearance → Interface scale** меняет размер всего меню.
Категории и основные подписи остаются английскими, а **Descriptions** или
кнопка RU/EN переключает пояснения. Поля поиска, профиля и группы PvP поддерживают
выделение, курсор и обычные сочетания Ctrl+A/C/V/X. Для меню и HUD файлы шрифтов
OTF уже включены в мод; устанавливать их в Windows отдельно не нужно.
Все текстовые поля новых HUD используют эти же OTF; маски иконок и набор
шрифтов сохраняются.

## Где хранятся настройки

Относительно папки профиля Minecraft:

```text
config/
└── bloodhelper/
    ├── client.json
    └── profiles/
        └── название профиля.json
```

Профиль сохраняет настройки модулей, оформление, клавишу и позиции HUD.
Это настройки, а не сохранённая история убийств. При загрузке профиля с другим
режимом Session Stats текущая сессия сбрасывается.
Сохранять его нужно через вкладку Profiles. Чтобы сбросить всё вручную, закрой
игру и переименуй `client.json`, например в `client.backup.json`; при следующем
запуске клиент создаст настройки по умолчанию. Именованные профили при этом
остаются в отдельной папке.

## Если что-то не отображается

| Симптом | Что проверить |
| --- | --- |
| Правый Shift не открывает меню | Запущен ли профиль 1.21.11 с Fabric; лежат ли JAR клиента и Fabric API в его `mods`; не изменена ли клавиша в настройках. |
| Списка предметов нет | Модуль включён и у предмета сейчас есть фактическая перезарядка. Для проверки положения используй редактор HUD. |
| Таймера PvP нет | Сервер действительно отправляет настроенную группу кулдауна. Мод не создаёт таймер боя самостоятельно. |
| Item Counter пуст или число неожиданное | Есть ли выбранные предметы, включено ли скрытие нулей; считаются только собственные 36 слотов и вторая рука. Кастомные варианты одной базы суммируются. |
| Armor HUD скрыт или показывает `—` / `∞` | Надета ли броня и включено ли скрытие пустого блока. `—` означает пустую позицию или отсутствие прочности, `∞` — неразрушимый предмет. |
| Notifications молчит при малом запасе | Первое низкое состояние не вызывает предупреждение. Проверь группу предупреждений и переход значения сверху через порог; Test позволяет увидеть карточку. |
| В Performance вместо ping стоит `—` | Клиент ещё не получил сведения о задержке. FPS и график кадров не заменяют ping или TPS. |
| В FFA убийства не прибавляются | Выбран ли FFA и пришло ли одно из двух заданных серверных сообщений. Произвольное сообщение об убийстве, монетах или текст игрока не засчитывается. |
| В FFA нет смертей, K/D или серии | В FFA предусмотрены только два счётчика убийств и необязательное время. Остальные поля относятся к SMP / MEETUPS; смена режима сбросит сессию. |
| Сессия обнулилась | Проверь смену режима, загрузку профиля с другим режимом, ручной сброс и настройку сброса при отключении. |
| Нет музыки | Игра запущена обычной Windows Java; приложение публикует медиасессию и трек включён. Статус виден в настройках Dynamic Island. |
| Нет обложки или прогресса | Плеер должен публиковать обложку и длительность. Для потокового эфира длительность может отсутствовать. |
| Нет текста песни | Выбран режим с текстом, выключен компактный вид для текста в островке, LRCLIB доступен и содержит синхронизированную версию именно этого трека. |
| Текст опережает или отстаёт | Настрой **Dynamic Island → More settings → Lyrics offset**. Положительное значение переводит выбор строки вперёд по времени трека. |
| Кнопки на островке не нажимаются | Открой чат, включи кнопки управления и полный вид; плеер должен поддерживать соответствующую команду. |
| HUD скрыт целиком | Проверь, не включён ли режим скрытия интерфейса клавишей F1. |

Для диагностики используются `logs/latest.log` и, при падении, файл из
`crash-reports` выбранного профиля. Не перепутай их с папкой другого профиля.

Результаты сборки и локального игрового прогона находятся в
[VERIFICATION_RU.md](VERIFICATION_RU.md). Совместимость с конкретным сервером,
другими модами и реальным медиаплеером требует соответствующей игровой сессии.
