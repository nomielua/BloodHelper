# Проверка BLOODHELPER 1.0.4 для Minecraft 1.21.11

12 октября 2026. Fabric Loader 0.19.5, Fabric API 0.141.6+1.21.11.
Компиляция `release=21`; отдельный тестовый Minecraft запущен на Java 25 под WSLg.
Запуск итогового remapped JAR в Windows-профиле на Java 21 отдельно не проверялся.

## GUI и собственный шрифт

Композиция меню адаптирована из опубликованного Expensive 4.0
`dest4590/Expensive_4.0`, коммит `3cf31b7ea09d28312e9743b2f5dd71498ba682a5`.
Донорский проект рассчитан на Minecraft 1.20.1; наша реализация — на 1.21.11.
Привязка этого репозитория к вложению темы YouGame 387054 не подтверждена.
Перенесены оформление и выбранные ресурсы GUI/шрифтов. Модули, авторизация,
сеть, обработка движения и сборка стороннего клиента не переносились и не запускались.

- Меню 800×500: боковая навигация, две колонки, настройки внутри карточек,
  чекбоксы, раскрывающиеся списки, ползунки и прокрутка. Исходный фон/активная
  вкладка перекрашены под BLOODHELPER, исходная геометрия сохранена.
- `CustomFont` напрямую загружает SF Pro Display Medium/Semibold из двух `.otf`.
  Файлы содержат по 2324 глифа; их SHA-256 совпадают с исходным архивом.
- Шрифт формирует собственные текстурные атласы: сглаживание AWT, дробные метрики,
  растеризация с четырёхкратным разрешением по каждой оси и усреднение покрытия,
  выбор разрешения по физическому масштабу экрана и линейная фильтрация текстур.
- Меню, HUD, HUD Editor и GuiTextField используют только CustomFont. Старые
  адаптеры Onest/GT к Minecraft Font/GlyphSource и соответствующий GUI-mixin
  удалены. Ванильный Font остаётся только в прежнем отдельном 3D-рендере текстов
  песен в мире; на отрисовку меню и экранного HUD он не влияет.
- Категории, модули и простые названия настроек английские. Описания и пояснения
  по умолчанию русские, имеется явный выбор RU/EN для описаний.
- Логотип — сохранённое пользовательское изображение 2088×336, без перерисовки.
  SHA-256: `dcce760bc2fad58c5e7bf60270d3bb86f25e5278e388171554f0c591dfc0cadf`.

## Проверки в настоящем клиенте

Итоговый прогон: `expensive-1.0.4-final.log`, завершён 12 октября в 21:27:31
(Asia/Yekaterinburg). `all Expensive GUI/custom font checks passed`; процесс
завершился с кодом 0.

- Проверены реальные OTF-гарнитуры, кириллица/Ё/ё, цифры, пропорциональность
  метрик размеру и ограничение ширины многоточием.
- Просмотрены игровые скриншоты меню 1280×800 и 960×600. Проверены окно 1920×1080
  при Minecraft GUI Scale 1 и 2: меню находится в окне и занимает не менее
  82% его ширины и высоты. Interface scale проверен реальными кликами: 0.65,
  1.05 и возврат к 1.00.
- Выполнена перезагрузка ресурсов с уже созданными атласами, принудительное
  обновление собственных шрифтов и повторная проверка OTF/метрик после неё.
- Русский поиск «музыка» оставляет только Dynamic Island. Проверены клик по
  отступу поля, ввод `AV office Яё`, Home/Right/Shift+Right, выделение,
  замена выбранного символа и Ctrl+A/Backspace. Снимок выделения сохранён.
- Переключены ISLAND/WORLD/BOTH/OFF и включение модуля Music.
- Через реальные кнопки сохранён, загружен и удалён профиль «Визуал»;
  перед загрузкой сохранённое значение изменяется, чтобы проверить восстановление.
- Проверены HUD Editor, перетаскивание, масштаб колесом, сброс позиций/якорей
  всех трёх виджетов. Сохранены стандартный/компактный HUD и масштаб 2 в 640×480.
- Проверка границ требует всех трёх виджетов с положительными размерами.
  Демонстрационный островок не регистрирует hitbox управления реальным плеером.
- В настоящем Minecraft проверены accessor-mixin менеджера кулдаунов,
  группа предмета, начальный/конечный тик и удаление завершившегося кулдауна.
- После визуальной проверки увеличен зазор между текстом строки кулдауна
  и полосой прогресса. Клики скрытых строк профилей ограничены областью списка.

## Сборка и проверки артефакта

`clean build runClient` завершился успешно. В JAR проверены 62 класса,
все с bytecode release21 и в собственном пакете `ru.bloodhelper.client`.
Тестовый мод, smoke-классы, удалённые адаптеры Minecraft GUI Font и старые
ресурсы Onest/GT в него не входят. Проверены metadata Minecraft 1.21.11,
версия 1.0.4, оба OTF, точные SHA-256 текстур и логотипа. Размеры и альфа-каналы
всех импортированных GUI PNG побайтно совпадают с донором..

13 JUnit-тестов покрывают конфигурацию/профили, LRC, интервалы фраз, выбор текстов
и отключение сетевых запросов. `mediaProtocolTest` проверяет сообщения медиасессии,
обложки, лимиты, защитные копии и завершение потока; настоящие Windows-процессы
и команды плееру в этой проверке не запускаются.

## Границы проверки

HUD на скриншотах показывает демонстрационные таймеры и трек. Не проверялись
сервер Bloodstone, реальная медиасессия Windows, команды плееру и 3D-окклюзия
в игровом мире. Проверка границ не запрещает намеренное перекрытие виджетов
при ручном расположении. Клиентские версии, профили и запущенные игры пользователя
не изменялись; отдельный тестовый экземпляр завершается сам.

## Повторение

`./gradlew build` / `gradlew.bat build` — сборка и тесты.
`./gradlew -Psmoke runClient` / `gradlew.bat -Psmoke runClient` — отдельный клиент.
Перед повторением smoke сохраните отдельно только
`run-smoke/config/bloodhelper/client.json`, чтобы проверить исходные настройки.
Скриншоты записываются в `run-smoke/screenshots`. Тестовый мод закрывает свои
службы музыки/текстов перед проверкой, чтобы не управлять настоящим плеером.
