# Устройство GUI BLOODHELPER 1.1.0+1.21.11

Заметки для разработчика описывают поведение целевой версии во время
интеграции. Имена вспомогательных классов и публичные сигнатуры могут уточняться;
они не являются контрактом для пользовательских инструкций. Успешная сборка
и завершённый игровой прогон здесь не заявляются.

`BloodHelperScreen` адаптирует двухколоночное меню Expensive 4.0 к Minecraft
1.21.11. Экран открывается как `new BloodHelperScreen(parent)`. Холст 800×500
вписывается в окно с отступом; пользовательский масштаб применяется относительно
вписанного размера. Отрисовка и ввод используют одну трансформацию.
При перетаскивании ползунка трансформация фиксируется до отпускания мыши,
чтобы ползунок Interface scale не уходил из-под курсора.

Меню содержит Visuals, Appearance, Profiles, About и кнопку HUD Editor.
На Visuals восемь модулей BLOODHELPER расположены в двух колонках:
Cooldowns, PvP Timer, Dynamic Island, Notifications, Item Counter, Armor HUD,
Performance и Session Stats. Карточки по умолчанию свёрнуты; это состояние
интерфейса не означает, что модули выключены. Заголовок раскрывает настройки
внутри карточки, Enable независимо управляет модулем, More settings
раскрывает расширенные параметры там же. Вся область карточек прокручивается,
отрисовка и нажатия ограничиваются видимой частью. Выпадающие списки
обрабатывают ввод поверх карточек. Их закрывают выбор, нажатие снаружи
или Esc. Esc при назначении клавиши отменяет назначение; Backspace
восстанавливает Right Shift.

Названия модулей и краткие подписи английские, описания по умолчанию русские;
RU/EN переключает пояснения. В Item Counter предусмотрены готовые варианты предметов
и **Add held item**: кнопка добавляет registry ID предмета из основной руки
в список до восьми уникальных типов. Это выбор категории подсчёта, а не снимок
числа предметов в руке. Разные серверные варианты одного базового ID образуют
одну категорию.

Session Stats предлагает **FFA / SMP / MEETUPS**, исходный режим — FFA.
Переключение режима сопровождается понятным предупреждением о сбросе и
сбрасывает статистику вместе со временем; это распространяется и на загрузку
профиля с другим режимом. В FFA видны два счётчика, общий и наградной,
и необязательное время. K/D, смерти и серия относятся к SMP / MEETUPS.
Параметр конфигурации `session.killMessageTemplate` задаёт пользовательский
шаблон серверного сообщения; наличие параметра не означает отдельного поля
в текущей карточке GUI. Он не расширяет
FFA-распознавание за пределы двух заданных форматов. Ручной сброс относится
к текущей сессии; профиль сохраняет настройки, а не её накопленные события.

Notifications содержит переключатели предупреждений о броне, предметах
и полезных эффектах, длительность, лимит карточек, необязательный звук
(по умолчанию выключен) и Test. Пороги брони и запаса берутся из соответствующих
модулей даже при скрытом HUD этих модулей. Отдельную карточку Effects HUD
не добавляем: стандартные индикаторы эффектов Minecraft не изменяются.

`CustomFont` отвечает за измерение и отрисовку меню/HUD из двух OTF:
SF Pro Display Medium и Semibold. Метрики и контуры получает AWT; глифы
попадают в собственные атласы после антиалиасинга и усреднения покрытия 4×4.
Размер растеризации учитывает трансформацию и физический GUI Scale,
а текстурный вывод использует линейную фильтрацию. Атласы принадлежат
`TextureManager`; `invalidate()` запрашивает отложенную повторную загрузку
без немедленного закрытия текстур, на которые ещё ссылается очередь GUI.
Измерение не требует GPU; отрисовка выполняется в потоке рендера.
Все новые HUD обязаны использовать этот путь для каждого текстового поля:
чисел и подписей, прочности и символов `∞` / `—`, FPS, ping, интервала кадров,
времени, счётчиков сессии и текста уведомлений. Метрики обрезки совпадают
с метриками рисования. Предметные иконки не должны подменять этот путь
vanilla-текстом количества или прочности. Существующие файлы OTF и маски
иконок сохраняются.

`GuiTextField` самостоятельно обрабатывает текст, курсор, выделение,
горизонтальную прокрутку и буфер обмена. Его используют Search, Profile name
и Cooldown group; новые текстовые настройки используют тот же путь.
Метрики для отображения и ввода едины. Поиск принимает
русские и английские ключевые слова. Имена профилей допускают буквы, цифры,
пробел, `_` и `-`; идентификатор группы PvP применяется только после успешного
разбора Minecraft Identifier.

Переключатели, выбор значений и новая клавиша сохраняются сразу;
ползунки — при отпускании; поле PvP — при потере фокуса и закрытии экрана.
Поисковый запрос не записывается в конфигурацию. Profiles сохраняет весь
корневой конфиг, Load применяет его сразу, Delete требует повторного нажатия
в течение пяти секунд. Ошибки сохранения показываются в меню.
Экран не ставит мир на паузу.

Все пять новых блоков регистрируются для отрисовки и выбора в HUD Editor,
поддерживают перетаскивание, масштаб 0,5–2, выравнивание, верхнюю/нижнюю
привязку и сохранение положения. Геометрия рисования и области выбора должна
совпадать, включая ограничение размером окна. R восстанавливает расположение,
Esc сохраняет и возвращает в меню. Предпросмотр использует демонстрационные
значения без записи в счётчики сессии и без создания реальных предупреждений.

Для каждого нового модуля доступны локальные Background и Text shadow.
Они работают совместно с глобальными `background` и `textShadow`:
локальное включение не отменяет глобальное выключение. Прозрачность и цвет
фона берутся из общей темы. Сохранение и загрузка профилей охватывают новые
секции конфига и их положения; отсутствующие секции получают значения
по умолчанию, числовые диапазоны и registry ID нормализуются при загрузке.

HUD и редактор используют `HudStyle`, делегирующий текст в `CustomFont`.
Рендер трёхмерных текстов песен остаётся отдельным путём через Minecraft
`Font` и Inter. Категории и краткие подписи английские; RU/EN меняет описания
и пояснения. Сведения о доноре, файлах и условиях происхождения:
[EXPENSIVE_GUI_RU.md](EXPENSIVE_GUI_RU.md).

Источники данных и ограничения новых модулей описаны в
[MODULES_1_1_RU.md](MODULES_1_1_RU.md). Состояние собственного инвентаря
используется только для чтения: 36 основных слотов и вторая рука для счётчика,
четыре надетых элемента для брони. Уведомления отслеживают пересечение порога,
а не вызываются из каждого кадра рисования. Сессия выводится из принятых
событий; отсутствие события не компенсируется предположением об убийстве.
Performance показывает клиентские измерения и полученный ping, без оценки TPS.

Для проверки поведения нужны запуск Minecraft и просмотр изображения:
маленькое/большое окно, разные GUI Scale и Interface scale, кириллический
поиск, выделение и буфер обмена, длинная прокрутка, назначение клавиши,
сохранение/загрузка профиля и перезагрузка ресурсов. Сборка Java не заменяет
эти проверки. Реальный сервер и медиасессия Windows требуют отдельных прогонов;
результаты фиксируются в [VERIFICATION_RU.md](VERIFICATION_RU.md).
Для 1.1.0 к этому относятся восемь свёрнутых карточек, раскрытие настроек
в обеих колонках, выбор предметов, смена режима сессии, все новые HUD при разных
масштабах и совместное действие общих и локальных флагов фона/тени.
Фактически выполненные проверки перечислены в VERIFICATION_RU.md.
Пользовательские [снимки форматов FFA](MODULES_1_1_RU.md#ffa) служат образцами
сообщений, а не доказательством проверки на сервере.
