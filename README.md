# BloodHelper 1.1.0

Публичный архив исходников **BloodHelper 1.1.0 для Minecraft Java 1.21.11**.
Это историческая версия с восемью модулями. Более новые версии клиента
развиваются отдельно и в этот репозиторий не включены.

Исходники, ресурсы, Gradle Wrapper, тесты, документация и уведомления об авторстве
восстановлены из сохранённого архива `BloodHelper-1.1.0+1.21.11-sources.zip`
без изменения файлов. [Происхождение и SHA-256](SOURCE_SNAPSHOT.json).

## Сборка

JDK 21 или новее; Gradle Wrapper 9.7.1. Для первого запуска нужен интернет.

```sh
./gradlew --no-daemon --max-workers=1 build
```

Windows PowerShell:

```powershell
.\gradlew.bat --no-daemon --max-workers=1 build
```

Результат: `build/libs/BloodHelper-1.1.0+1.21.11.jar`.
