# Оформление BLOODHELPER

Прозрачный логотип — `bloodhelper-logo.png` (1253×158). Это единое изображение
**BLOOD + красное пиксельное сердце + HELPER**: сердце находится между словами,
а не отдельно под надписью. Превью на обычном тёмном фоне —
`bloodhelper-preview.png` (1301×206). Квадратная пиксельная иконка —
`bloodhelper-icon-256.png` (256×256); исходный размер — 64×64.
В `bloodhelper-preview-375.png` сам логотип уменьшен до ширины 375 пикселей:
это проверка читаемости в интерфейсе, без увеличения мелкого превью.

В клиенте используются:

- `assets/bloodhelper/textures/logo.png` — единый логотип BLOOD, сердце, HELPER;
- `assets/bloodhelper/textures/icon.png` — сердце для интерфейса;
- `assets/bloodhelper/icon.png` — иконка Fabric/Mod Menu.

Красная часть BLOOD взята из оригинального логотипа Bloodstone. Серебристая часть
HELPER полностью переработана из настоящих букв исходника: E использует поверхность
исходной E, L — исходной L, H построена из O, а P и R — из B. Генератор сначала
убирает перспективный скос исходных букв, затем собирает новые очертания и
возвращает единую перспективу. Сохранены толстые штрихи и узкие просветы исходника,
настоящие трещины и материал серебристой E. Чёрный внешний контур имеет толщину
7 пикселей, нижние объёмные грани — глубину 32 пикселя. Старые самостоятельные
тонкие глифы HELPER больше не используются.

Между словами вставлен настоящий `pack.png` из указанного
пользователем ресурспака, увеличенный ровно вдвое (128×128) без сглаживания.
Это изображение сердца, не символ шрифта или эмодзи. Подложки у основного логотипа
нет; отдельной рамки или второго сердца в превью тоже нет. Для квадратной иконки
использован тот же исходный `pack.png`, с сохранением прозрачности.

Для отрисовки в GUI следует использовать изображение целиком с соотношением
сторон **1253:158**. Нельзя заменять его текстовой надписью `BLOODHELPER` или
отрисовывать только квадратную иконку. Например, ширине 300 соответствует высота
около 38 экранных пикселей.

## Повторная генерация

Требуются Python 3 и Pillow:

```sh
python branding/build_branding.py
```

Генератор работает локально, не скачивает файлы и не устанавливает зависимости.
Его входные данные — сохранённые исходные изображения. Результаты копируются в
ресурсы клиента и в эту папку.
