# Логотип BLOODHELPER

Текущий логотип — **именно изображение, присланное пользователем 12 октября 2026**:
красная надпись BLOOD и белая HELPER, с исходными трещинами, чёрным контуром и
глубокими нижними гранями. Пользователь выбрал этот рисунок вместо предыдущего
варианта. Сердце между словами в новой надписи отсутствует, как в присланном
изображении. Самостоятельная квадратная иконка сердца не изменена.

## Файлы и размеры

- `source/user-logo-2026-10-12.png` — неизменённое изображение пользователя, **2172×724**;
- `bloodhelper-logo.png` — логотип на прозрачном фоне, **2088×336**;
- `bloodhelper-preview.png` — обычное превью на тёмном фоне, **2120×368**;
- `bloodhelper-preview-375.png` — проверка при ширине самого логотипа 375 px;
  размер файла с полями **407×92**;
- `../src/main/resources/assets/bloodhelper/textures/logo.png` — тот же PNG
  для использования в клиенте.

В GUI нужно сохранять пропорции **2088:336**. При ширине 375 px высота равна
примерно 60 px. Надпись следует рисовать целиком как изображение.

## Обработка исходника

Исходный файл сохранён без изменений. Удалены пустые поля; внешняя тёмная подложка,
связанная с краями изображения, сделана прозрачной. Для этого используется
заливка от края, которая останавливается на чёрном контуре букв. Замкнутые части
рисунка, чёрные просветы, трещины, красные и белые поверхности не перерисовываются.

Из исходника взят прямоугольник **(42, 175) — (2130, 511)**, включая 4 пикселя
прозрачного отступа вокруг контура. **RGB каждого пикселя готового PNG совпадает
с соответствующим пикселем исходника**; изменена только прозрачность внешнего
фона. Генератор проверяет это при каждом запуске. Сам логотип не масштабируется,
не сглаживается заново, не перекрашивается и не проходит генеративную обработку.
Уменьшение выполняется только для отдельного превью 375 px.

Контрольные суммы исходников и результатов, размеры и координаты обрезки
записаны в `manifest.json`.

## Повторная подготовка

Требуются Python 3 и Pillow:

```sh
python branding/build_branding.py
```

Штатный скрипт использует только сохранённое изображение пользователя. Он не
скачивает файлы и не изменяет квадратную иконку сердца.

Предыдущий генератор букв, его документация, manifest и прошлый логотип
сохранены в `legacy/` для истории. Они больше не используются при сборке клиента.
